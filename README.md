# GitHub Pages portfolio

This is a standalone, build-free portfolio website. It contains no Canva dependency and is designed to be published only with GitHub Pages.

## Publish at `alkamehra-creativepulse0078.github.io`

1. Sign in to GitHub and create a **public** repository named exactly `alkamehra-creativepulse0078.github.io`. This exact repository name is what produces the personal-site address.
2. Upload every file from this folder to the repository root. Keep `index.html` at the top level.
3. Open the repository’s **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)`, then save.
4. After GitHub completes the deployment, the site will be at `https://alkamehra-creativepulse0078.github.io/`.
